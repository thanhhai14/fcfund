# Tài liệu nghiệp vụ FC Fund

Thư mục này là nguồn mô tả nghiệp vụ và cấu trúc dữ liệu trước khi phát triển ứng dụng.

## Nguyên tắc làm việc

1. Phân tích dữ liệu thực tế.
2. Ghi rõ dữ kiện, giả thuyết và điểm chưa rõ.
3. Chủ quỹ xác nhận hoặc sửa nghiệp vụ.
4. Hoàn thiện mô hình dữ liệu, công thức tính và quy trình.
5. Chỉ bắt đầu xây dựng ứng dụng sau khi tài liệu được duyệt.
